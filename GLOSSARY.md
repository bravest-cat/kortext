# Kortext Ubiquitous Language & Domain Glossary (`GLOSSARY.md`)

Canonical domain terminology for Kortext v2.1+. Agents, specifications (`to-spec`), Architecture Decision Records (`docs/adr/`), and Task DAG briefs (`to-tickets`) must use these exact terms rather than verbose paraphrases.

| Canonical Term | Definition & Architectural Invariant | Primary Module / Substrate |
|---|---|---|
| **Tier 0 Symbol Graph** | Deterministic Tree-sitter AST and SCIP compiler graph indexing declarations, signatures, line bounds, imports, and call edges in FalkorDB (`kortext_symbols`), queried via `seek_symbol` and `trace_symbol_impact`. | `kortext/symbols/` |
| **Tier 1 Hybrid Vector Store** | Dual-vector Qdrant index combining dense embeddings (`text-dense`, 384-d FastEmbed ONNX or 4096-d remote) with sparse BM25 vectors (`text-sparse-new`). | `kortext/retrieval/qdrant_engine.py` |
| **Tier 2 Bi-Temporal Episodic Graph** | FalkorDB property graph (`kortext`) storing `:Episodic` outcomes, disambiguated `:Entity` nodes, and `:RELATES_TO` edges across World Time (`valid_from`, `valid_to`) and System Time (`transaction_time`, `superseded_at`). | `kortext/episodic/driver.py` |
| **Tier 3 Architectural Overview** | Concise file skeletons (`ast_skeleton`) and Louvain community subsystem summaries (`:Subsystem`) providing macro-level repository topology. | `kortext/chunking/skeleton.py`, `kortext/symbols/clustering.py` |
| **Sole Custodian Invariant** | Only the primary `kortext.server` daemon process may hold the exclusive portalocker file lock on `~/.kortext/qdrant`. Client editor windows and hooks must route requests through the daemon rather than instantiating `QdrantClient(path=...)` directly. | `kortext/_qdrant.py`, `kortext/daemon.py` |
| **FastMCP Daemon & Stdio Proxies** | Single background daemon per machine on `127.0.0.1:8767` owning the vector store and database connections, with editor windows connecting through stdio proxy instances that start the daemon on demand and forward calls. | `kortext/daemon.py`, `kortext/server.py` |
| **Memory Vault** | Human-readable Markdown storage (`.kortext/memory/` or `~/.kortext/journal/<project>/`) maintaining daily technical decision logs, secret-redacted session history, and auto-generated 40-line `INDEX.md` index files. | `kortext/vault.py` |
| **Stale Memory Marking** | Grounding episodic facts to AST symbol body hashes; queries annotate outdated memories with `[may be out of date: <symbol> changed since this was recorded]` when code symbols change or vanish. | `kortext/episodic/driver.py`, `kortext/symbols/graph.py` |
| **Overview Dashboard Tab** | Default landing view (`/#overview`) displaying live daemon status, FalkorDB and Qdrant connectivity, re-index spool queue diagnostics, project freshness, and token savings metrics. | `kortext/dashboard/static/js/modules/overview.js` |
| **Memory Inbox Dashboard Tab** | Dedicated dashboard view (`/#memory`) providing search, inspection, approval, editing, and soft-superseding of episodic facts with CSRF protection. | `kortext/dashboard/routes/memory.py`, `kortext/dashboard/static/js/modules/memory.js` |
| **Anti-Ripgrep Mandate** | Prohibition against brute-force `rg` or unindexed text scans across source code when locating symbol definitions or call graphs. Always use `seek_symbol` and `trace_symbol_impact`. | `kortext/hooks/pipelines/pre_tool.py` (`AntiRipgrepGate`) |
| **GateGuard First-Touch Credit** | PreToolUse blast-radius policy requiring `seek_symbol` or `trace_symbol_impact` inspection in the active turn before modifying high-in-degree ($\ge 5$ callers) or core architectural files. | `BlastRadiusGuard` |
| **Trust-Tier Execution Fence (MINJA Defense)** | Provenance state machine (`untrusted: 0.3`, `speculative: 0.5`, `tool_confirmed: 0.6`, `verified: 0.8`, `user_approved: 1.0`, `system: 1.0`). Exposure never validates: reading a memory never promotes its trust score, and only `tool_confirmed` or higher may be distilled into executable skills. | `kortext/trust/sanitizer.py` |
| **MEX AST Grounding** | Binding an architectural invariant (`grounds_to`) to a symbol's normalized signature hash, AST body SHA-256 hash, and symbol-scoped token-trigram MinHash sketch to detect code drift and cross-file symbol relocation. | `kortext/invariants.py` |
| **Handoff Baton** | Atomic compare-and-swap JSON artifact (`~/.kortext/handoffs/<id>.json`) with a `<150`-token summary transferring context between sessions, compaction boundaries, or subagent workers without context bleed. | `kortext/handoff.py` |
| **Wayfinder Frontier** | Unblocked leaf tickets in the FalkorDB Task DAG (`get_ready`) where interfaces are known, separated from unexplored zones requiring research or prototyping tickets first. | `kortext/tasks/tracker.py`, `skills/to-tickets/` |
| **25% Compaction Ceiling** | Attention-degradation boundary (~200k to 250k tokens on 1M-window models; ~75% on 200k models) triggering Stage-1 (60% budget) advisories and Stage-2 (80% budget) automatic handoff checkpointing. | `kortext/hooks/transcript_tokens.py` |
